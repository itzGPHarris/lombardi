# F34: The coach asking how something went

*A pass for spec v0.20 and the backlog · October 17, 2026*

Greg raised this on October 17, 2026. Everything designed so far helps her get through the week ahead, borrowing from boarding passes, flight control and subway lines. Nothing yet looks back. A short look-back after something has happened would give her a place to let off steam or enjoy something that went well, and it would tell the coach what to plan differently next time. Greg was clear that it is not a journal.

Following the project rule, the idea gets an F-number before anything else happens to it, and the backlog lists it under Parked. The spec text below is ready to fold into v0.20 whenever that version is next cut. Because nothing else has changed, this pass does not create a spec version by itself.
